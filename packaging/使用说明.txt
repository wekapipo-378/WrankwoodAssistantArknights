蓝卡坞方舟助手  v0.1.0（预览版）
WrankwoodAssistantArknights (WAA)
================================

怎么启动
--------
1. 双击 WAA.exe
2. 程序会自己请求管理员权限，在 UAC 窗口点「是」（触摸注入没有管理员权限
   会被系统静默丢弃，表现为点了没反应）
3. 出现 waa> 提示符就是启动成功；输入 help 看全部命令
4. 启动时会自动打开悬浮帧窗（三行：帧号 / 时间 / 费用条）。不想要的话：
   - 临时一次：WAA.exe --no-showframe
   - 永久关掉：在控制台输入 showframe auto off（下次启动不再自动开）
   - 再打开：showframe auto on，或直接输入 showframe

第一次使用
----------
1. 游戏用窗口模式，16:9，UI 缩放 100%
2. 输入 update 拉取地图/头像/角色表（约 300MB，需要机器上装有 Git；
   如果构建时带了 resources，可跳过这步）
3. 输入 load 选轴，或直接 load axes\1-7test.xlsx
4. 输入 run 开始执行；F6 暂停/恢复，F5 打轴记帧

新建一条轴
----------
输入 write new → 选保存位置 → 程序会把内置标准模板复制过去，并把它设为 F5 写入目标。
模板有三页：作战记录（帧号1/帧号2/操作/单位/坐标/朝向/简称）、运行信息、地图示意。
注意：
- write new 只创建「写入目标」，不会自动 load；填好动作后要再 load 那个文件才能 run。
- 内置模板在 _internal\waa\templates\ 里；改 axes\WAA_标准模板.xlsx 不会影响新建，
  要改默认模板得改 waa\templates\WAA_标准模板.xlsx 后重新打包。

出问题先跑自检
--------------
    WAA.exe --selftest

会逐项检查依赖、随包资源、out 写权限、帧窗程序、OCR 语言包，
哪一项 FAIL 就是哪一项的问题。

日志与输出
----------
    out\logs\run_*.log      每次 run 的完整输出（头部有版本号）
    out\pause_log.csv       暂停落点
    out\run_status.json     最新状态
    out\bar_shots\ 等       测试夹具，回归测试要用，不要删

注意
----
- 这是早期预览版，只在开发者本机验证过；轴格式和控制台命令随时可能变。
- Excel 面板需要本机装有 Excel（走 COM）。
- 关闭控制台窗口时，悬浮帧窗会跟着关闭。
